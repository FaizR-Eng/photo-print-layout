# Manual checklist (after Install.cmd)

Tick each item. Use copies of photos, never originals you can't replace.

| # | Check | How | OK? |
|---|---|---|---|
| 1 | Start menu | Start → type "Photo Print Layout" → it opens, title shows **1.4** | ☐ |
| 2 | Right-click, one photo | Right-click a .jpg → **Show more options** → **Open in Photo Print Layout** → the photo appears | ☐ |
| 3 | Right-click, several photos | Select 5 photos → right-click → Show more options → Open in Photo Print Layout → **one** window with all 5 | ☐ |
| 4 | Send To | Select photos → right-click → Show more options → **Send to → Photo Print Layout** → same window | ☐ |
| 5 | Already open | With the app open, right-click another photo → it is **added** to the open window | ☐ |
| 6 | Toolbar | **Print…** and **Print preview…** visible at the top without scrolling; Ctrl+P opens Print | ☐ |
| 7 | Print window | Change printer / paper / Portrait-Landscape → preview changes at once; **Printer preferences…** opens your printer's own settings | ☐ |
| 8 | Real print (optional, plain paper) | Choose **10 × 15 cm** under Photo size, print 1 page, measure with a ruler: 15.0 × 10.0 cm | ☐ |
| 9 | Settings kept | Your printer, paper and margin are the same as before installing | ☐ |
| 10 | Settings > Apps | "Photo Print Layout" is listed (version 1.4.0.0) | ☐ |
| 11 | Uninstall (later, optional) | Run Uninstall.cmd → app, Start menu entry, right-click entry and Send To are gone; your settings stay | ☐ |
